# DataWipe – Secure Data Erasure Tool

DataWipe securely deletes files using data-overwriting techniques so they cannot be recovered.

## Features
- Zero Pass overwrite
- Random Data overwrite
- DoD 3-Pass secure erasure
- GUI using Tkinter
- Progress status + success alerts

## Tech Used
- Python
- Tkinter
- OS & Random modules

python main.py
